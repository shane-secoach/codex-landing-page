# Charles Dowding’s Sowing Timeline landing page concept

This is a simple static landing page for an app idea focused on helping growers sow seeds at the right time.
It uses plain HTML, CSS, and JavaScript only.

## What this page is

The page includes:

- A hero section that frames the app concept
- Two action buttons for navigating the page
- A feature section covering sowing timing, seed buying, materials, and seedling protection
- A timeline flow section with practical example reminders
- A mini interactive timeline planner that generates stage-based task lists
- A simple footer

## How to open it locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` (or right-click and choose your browser).

No server, framework, or build step is required.

## How to edit text and links

- **Main page content**: edit `index.html`
- **Colours, spacing, and layout**: edit `styles.css`
- **Small interactions**: edit `script.js`

After changes, save and refresh the browser tab.
