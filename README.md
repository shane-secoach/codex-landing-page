# Shane Evans Coaching landing page

This is a very simple static personal landing page for a UK-based leadership coach.
It uses plain HTML, CSS, and JavaScript only.

## What this page is

The page includes:

- A hero section with a clear headline and short intro copy
- Two main action buttons (book a call and LinkedIn)
- A "What you get" section with four short coaching outcomes
- A testimonials section with placeholder quotes
- A simple footer with an email placeholder and LinkedIn link

## How to open it locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` (or right-click and choose your browser).

That is all you need. No server, framework, or build step is required.

## How to edit text and links

- **Main page content**: edit `index.html`
  - Headline, body copy, button text, section text, and footer text all live here.
- **Colours, spacing, and layout**: edit `styles.css`
- **Small interactions**: edit `script.js`
  - Smooth scrolling for internal links
  - Console log when the primary button is clicked

After any changes, save the file and refresh the browser tab.
